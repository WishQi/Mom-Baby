# Mom-Baby 高保真原型

这是一套无外部依赖的 iPhone MVP 原型，视觉基准为 `390 × 844`。内容覆盖 PRD 的首次使用、今日记录、亲喂、吸奶、配方奶追溯、尿布、成长、相册、历史和用品档案。

## 两个入口

- `index.html`：完整可点击交互原型。桌面端左侧带流程导航，手机宽度下自动隐藏导航并铺满屏幕。
- `board.html`：Figma Code-to-Canvas 设计板。将 28 个关键状态展开为独立、带编号的 `390 × 844` 画板，适合一次捕获后转成可编辑图层。

## 本地启动

原型没有 npm 依赖。可直接双击 HTML，也可以在项目根目录启动静态服务器：

```bash
python3 -m http.server 4173 -d prototype
```

然后访问：

- 交互原型：`http://localhost:4173/index.html`
- Figma 设计板：`http://localhost:4173/board.html`

建议使用 Chrome 或 Safari。交互数据会保存在当前浏览器的 `localStorage`；桌面左侧的“重置原型数据”可恢复初始状态，键盘按 `R` 只返回欢迎页。

## 推荐评审路径

1. 欢迎 → 监护人同意 → 宝宝建档 → 模块选择 → 今日首页。
2. 今日 → 亲喂 → 开始左侧 → 切到右侧 → 暂停/继续 → 结束 → 详情。
3. 今日 → 吸奶 → 双边同时开始 → 结束左侧 → 结束剩余侧并填写用量 → 详情。
4. 今日 → 奶瓶 → 添加奶粉罐 → 三步模拟拍摄 → 字段核对 → 添加奶瓶 → 保存本次瓶喂。
5. 从底部导航和全局 `+` 继续体验尿布、成长、相册、历史与用品档案。

拍摄和照片选择在原型中使用本地示意占位，不会读取或上传真实文件。原型中的品牌、批次、用量和生长数值均为虚构示例，不构成产品安全或医疗判断。

## 设计约束

- 暖灰底色与鼠尾草绿作为主视觉，桃色、浅金、雾蓝只区分事件类别。
- 间距遵循 8pt 网格，主要点击目标不小于 44pt。
- 使用系统字体，无 Web Font、图片 CDN、组件库或网络请求。
- `max-width: 760px` 时切换为手机全屏，`max-width: 350px` 时进一步收紧间距。
- 深色计时页降低夜间刺激；产品文案只陈述记录事实，不输出健康或安全结论。
